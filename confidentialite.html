Politique de confidentialité

Kyridril - Erynd Var · Volta Games · mise à jour le 1er novembre 2026

Assistance · English summary · Jouer

En bref

  • Aucune donnée personnelle n’est collectée. Il n’y a pas de compte, pas d’inscription, pas d’identifiant.
  • Ta progression reste sur ton appareil. Elle n’est envoyée à personne, ni à nous ni à un tiers.
  • Pas de publicité, pas de mesure d’audience, pas de pistage, aucun outil tiers qui collecte des données.

1. Qui sommes-nous ?

Kyridril - Erynd Var est un jeu édité par Volta Games. Pour toute question sur cette politique : [adresse e-mail de contact].

2. Les données que nous collectons

Aucune. Le jeu ne demande ni nom, ni adresse e-mail, ni âge, ni position, ni contacts, ni photos. Il ne crée aucun identifiant publicitaire ou technique, et ne transmet aucune donnée d’utilisation ni de diagnostic. Nous n’avons pas de serveur qui recevrait des informations sur les joueurs.

3. Ta progression, gardée sur ton appareil

La partie (or, arènes franchies, améliorations, réglages, statistiques de jeu) est enregistrée uniquement en local :

  • dans le navigateur ou le jeu installé depuis le navigateur : stockage local du navigateur (localStorage) et une copie dans sa base locale (IndexedDB) ;
  • dans les applications iOS et Android : le stockage interne de l’application (Preferences : UserDefaults sur iOS, SharedPreferences sur Android).

Ces données ne quittent pas l’appareil. Désinstaller l’application, ou effacer les données du site dans le navigateur, les supprime définitivement.

4. Le code de transfert

Pour changer d’appareil, le jeu peut produire un code de transfert (KEV1-…), un fichier .kev ou un QR code. Il ne contient que la progression de jeu, aucune donnée personnelle. Il est créé sur l’appareil et ne passe par aucun de nos serveurs : c’est toi qui choisis de le copier, de l’enregistrer ou de le partager (par exemple avec la feuille de partage de ton téléphone). Le lien du QR code ouvre le jeu avec le code placé après le signe # de l’adresse : cette partie n’est pas envoyée au serveur web.

5. Connexions réseau

Le jeu ne fait aucune requête réseau pour lui-même : pas d’analyse, pas de publicité, pas de service tiers. Dans la version web, le navigateur télécharge seulement les fichiers du jeu depuis GitHub Pages (hébergeur du site), qui peut, comme tout hébergeur, traiter des journaux techniques (adresse IP) pour servir et sécuriser le site ; voir la déclaration de confidentialité de GitHub. Une fois chargé, le jeu se joue hors connexion. Les applications iOS et Android contiennent tous les fichiers du jeu et n’ont pas besoin du réseau pour jouer.

6. Publicité, mesure d’audience, pistage

Il n’y en a pas. Le jeu n’intègre aucun kit tiers (SDK) de publicité, d’analyse, de rapport de plantage ou de réseau social, et ne pratique aucun pistage au sens d’Apple (App Tracking Transparency) ou de Google.

7. Achats intégrés (à venir)

La version actuelle ne propose aucun achat. Si des achats intégrés sont ajoutés, le paiement sera entièrement traité par Apple (App Store) ou Google (Google Play), selon leurs propres politiques de confidentialité. Nous ne recevons ni ne conservons tes informations de paiement ; le jeu ne recevra que la confirmation de l’achat fournie par le store. Cette page sera mise à jour avant leur arrivée.

8. Enfants

Le jeu ne collecte aucune donnée, y compris auprès des enfants. Aucune information personnelle n’est demandée ni transmise, quel que soit l’âge du joueur.

9. Tes droits

Comme nous ne détenons aucune donnée te concernant, il n’y a rien à consulter, corriger ou supprimer chez nous : tes données de jeu sont sur ton appareil et tu peux les effacer à tout moment (voir § 3). Pour toute question : [adresse e-mail de contact].

10. Modifications

Si cette politique change (par exemple à l’arrivée des achats intégrés), la nouvelle version sera publiée sur cette page avec sa date de mise à jour.

English summary

  • Kyridril - Erynd Var (Volta Games) collects no personal data. There is no account, no sign-up and no identifier.
  • Game progress is stored only on the device (browser localStorage / IndexedDB on the web, the app’s local Preferences storage on iOS and Android). It is never sent to us or to anyone else.
  • The optional transfer code (to move a save to another device) contains game progress only, is generated on the device and is shared only if the player chooses to.
  • No analytics, no advertising, no tracking, and no third-party SDK that collects data. The app makes no network requests of its own; the web version only downloads the game files from its host (GitHub Pages).
  • Children: no data is collected from anyone, including children.
  • In-app purchases (planned, none in the current version) will be processed entirely by Apple or Google; we never receive payment details.
